# Vrinda Store Sales Analysis

## Project Overview
This project analyzes Vrinda Store retail sales data using Microsoft Excel. It includes a sales dashboard, monthly sales and order trends, gender-wise sales, order status, customer age-group analysis, sales by state, and sales channel performance.

## Tools Used
- Microsoft Excel
- Pivot Tables and Pivot Charts
- Data Analysis and Business Insights

## Dataset
- 31,047 transaction records
- 21 columns
- Data period: 2022
- Currency: INR

## Key Findings
- Total recorded sales amount: ₹21,176,377
- Women sales amount: ₹13,562,773
- Men sales amount: ₹7,613,604
- Top sales states: Maharashtra, Karnataka, and Uttar Pradesh
- Amazon has the highest recorded sales amount among the listed channels.

## Business Recommendation
Focus marketing campaigns on high-performing states and customer segments, and evaluate channel performance to identify opportunities for sales growth.

## Data Notes
The workbook contains 31,047 records and 28,471 unique Order IDs. These are different measures. Quantity values should be standardized before calculating total units. Sales figures represent the `Amount` column total and should not automatically be interpreted as profit.
